# 歴史マスター

アジア7地域の国・王朝・歴史を探究するAndroidアプリ。Java / Android Views / Material Components。

## 2.0 の改善

- 紺の文字・青緑の操作色・明るい背景に統一。大きな文字、スクロールできる画面、明示的な戻る導線。
- 中国、日本、朝鮮半島、モンゴル、ベトナム、カンボジア、ラオスの選択と前回の地域の復元。
- 地域史の概観と、時代・国・王朝の項目からWikipediaの解説へ移動。入れ子の項目も表示・検索。
- 読了を自分で記録し、地域別の学習進捗とクイズ最高点を端末に保存。
- 5問クイズと10問テスト。教材の関連語に基づく問題と回答後の根拠を表示。再回答による重複加点を防止。
- 未実装のアダプター・ダイアログ参照を解消。教材をAndroidのassetsへ移動。中国・日本・朝鮮半島の既存JSONの構文破損も修復。

## Wikipedia

日本語版MediaWiki Action APIの `prop=extracts|pageprops` で記事冒頭をプレーンテキスト取得します。リダイレクトは追跡し、曖昧さ回避・欠落・空本文は解説として表示しません。地域ごとの概観記事名は `data/Regions.java` で管理します。

本文は原文の抜粋であり、自動生成した説明ではありません。画面には出典、元記事（履歴・投稿者を確認可能）、ライセンス案内を表示します。個別記事の正確なライセンス・追加条件は元記事を参照してください。

通信はバックグラウンドの上限2スレッドで実行し、接続10秒・読込15秒のタイムアウトを設定。取得成功本文は端末に保存し、再表示時は保存本文を表示しながら更新を試みます。初回オフライン時はエラーと再取得・外部検索導線を表示します。端末からアプリデータを削除すると保存本文・進捗も消去されます。

教材には複数の出来事をまとめた項目名もあり、同名のWikipedia記事が存在しない場合があります。その場合はエラーを明示し、記事名検索を案内します。検索結果の先頭記事を自動的に採用しない設計です。教材の関連語自体をWikipediaで検証・補正する処理はありません。

## 開発と検証

JDK 17、Android SDK 33、インターネット接続が必要です。

```sh
bash gradlew testDebugUnitTest lintDebug assembleDebug
```

GitHub Actionsでも同じ検証を実行し、デバッグAPKとレポートをArtifactsに保存します。APKはActionsの `history-master-debug` から取得できます。

### 実機での確認項目

1. 7地域を切り替え、地域の復元と各教材の表示を確認。
2. 地域史・個別記事を開き、出典・元記事・読了の保存を確認。
3. 初回オフライン・取得後オフライン・欠落記事・再取得を確認。
4. 検索で親項目・子項目・タグと該当なしを確認。
5. クイズ／テストの回答、連打、結果、最高点、途中での回転・再生成を確認。
6. 小画面・文字拡大・横画面・TalkBackで操作を確認。

この修正の作業環境にはAndroid SDKがなく、Gradle配布先への接続も制限されていたため、ローカルAPKビルド・実機表示は未検証です。
