# Jipains

アジア7地域の国・王朝を、短いレッスンと図鑑で探究するAndroidアプリ。Java / Android Views / Material Components。Android 7.0以上。

## 3.0

- 紫・ラベンダー・濃い文字のデザインへ刷新。固定の「学ぶ／図鑑／復習／記録」ナビゲーション。
- オリジナルのキツネ「Jipi」、短い登場・正解アニメーション、達成時の紙吹雪。動きを減らす設定とOSのアニメーション設定を尊重。
- 7地域・14レッスン・42問。3つの要点を読んで3問に挑戦し、2問以上の正解で次へ。地域ごとの6問チェックポイントも搭載。
- XP、レベル、連続学習、今日の目標、クエスト、実際の進捗に連動するバッジ。連打・画面再生成による二重加点を防止。同日の同一レッスン再挑戦は加点なし。
- 間違えた問題は復習へ。正答すると復習待ちから除外。途中の回答とレッスンは端末に保存。
- 全地域横断検索、地域・お気に入り絞り込み、40件ずつの追加表示。既存304項目の図鑑も維持。
- Wikipediaの本文・出典・記事版・取得日・ライセンス案内、キャッシュと再取得。読了とお気に入りを保存。
- 振動・効果音・動きを減らす設定、1日の目標XPを選択。音は初期状態でオフ。

## 教材とWikipedia

新コースは `app/src/main/assets/courses.json` に収録した出典付きの基礎問題です。[教材出典](CONTENT_SOURCES.md)を参照してください。既存図鑑のタグから推測して新コースの問題を生成することはありません。既存図鑑の全項目・タグの史実検証は未完了です。

日本語版MediaWiki Action APIで記事冒頭をプレーンテキスト取得します。リダイレクトと明示的な別名対応を使用し、曖昧さ回避・欠落・空本文を解説として採用しません。記事が見つからない場合は検索導線を表示し、検索結果を勝手に解説へ置き換えません。

本文はWikipedia原文の抜粋です。出典・履歴・取得時の記事版とCC BY-SA 4.0の案内を表示します。個別記事の追加条件は元記事を確認してください。接続10秒・読込15秒のタイムアウト、キャンセル、本文サイズ制限を設けています。保存本文は通信に失敗しても閲覧できます。初回取得には通信が必要です。

進捗・復習・記事は端末内に保存されます。旧バージョンの読了・お気に入り用設定を維持しています。クラウド同期はなく、アプリデータを削除すると保存内容も消えます。

## ビルド・検証

JDK 17、Android SDK 33、インターネット接続を用意します。

```sh
bash gradlew testDebugUnitTest lintDebug assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`。GitHub Actionsの `jipains-debug` にも出力します。

17件の自動テストで教材整合性、回答状態の復元、XP重複防止、日付境界、記事応答解析、復習登録・解消、実際のAndroid画面操作を検証します。Robolectricのネイティブ描画で生成する画面画像は `app/build/reports/ui/` に保存されます。

端末での最終確認項目: 小画面・文字拡大・横画面・TalkBack、アニメーションと効果音の体感、Android上のオンライン／オフライン切り替え、バックグラウンドからの復帰。ローカルのAndroid描画テストは実機テストを代替するものではありません。
